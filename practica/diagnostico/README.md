Mini Help Desk

## 2. Integrantes
- Jonathan Larraguibel

## 3. Problema que resuelve
Las incidencias técnicas internas de la organización se reportan hoy de forma informal, sin registro centralizado, lo que hace perder información y dificulta saber qué incidencias están pendientes, en progreso o resueltas. Mini Help Desk centraliza el registro, seguimiento y filtrado de incidencias para el operador de soporte. Detalle completo en `docs/requerimientos.md`.

## 4. Tecnologías utilizadas
- Backend: Java 21 + Spring Boot 4.x
- Frontend: React + Vite + JavaScript
- Base de datos: PostgreSQL
- Infraestructura: Docker + Docker Compose
